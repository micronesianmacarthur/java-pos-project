## Admin User Stories

### 1
**Title:**
As an Admin, I want to add, edit, and delete users, so that I can manage who can access the system.

**Acceptance Criteria:**
1. Menu to add user must be present.
2. In add user, option to assign role must be present.
3. Option to edit must be present
4. In edit page, option to toggle active/inactive status must be present
5. Option to delete user must be present.

**Priority:** High
**Story points:** 2
**Notes:** 

### 2
**Title:**
As an Admin, I want to reset user password, so that I can set new password for the user.

**Acceptance Criteria:**
1. Option to reset user password must be present.

## Manager User Stories
### 1
**Title:**
As a Manager, I want to add, edit users, so that I can manage who can access the system.

**Acceptance Criteria:**
1. Menu to add user must be present
2. Option to edit user must be present
3. Adding user must include role
4. Edit user must have option to toggle active/inactive status

**Priority:** High
**Story points:** 2
**Notes:**

### 2
As a Manager, I want to add categories, so that products can be managed by category.

**Acceptance Criteria:**
1. Menu to add category must be present.
2. In add category page, must include fields category name, category code

**Priority:** High
**Story points:** 2
**Notes:**

### 3
**Title:**
As a Manager, I want to return sale item, so that inventory can be managed efficiently.

**Acceptance Criteria:**
1. Option to return sale item must be present.
2. In return sale page, items can be removed from cart.
3. On successful return, item quantity is removed from sale and added to stock_level in database.

**Priority:** High
**Story points:** 5
